## 1. 제품 개요
BGM Canvas는 사용자가 캔버스 위에서 미리 제공된 모티프 가이드를 선택하거나 따라 그리면, 시스템이 해당 입력을 제한된 장면 모티프로 해석해 어울리는 BGM과 환경음을 추가하는 웹 서비스다. 사용자가 새로운 요소를 계속 추가할수록 사운드는 단일 효과음이 아니라 여러 레이어가 쌓인 풍성한 배경음으로 발전한다.

이 제품의 핵심 가치는 `복잡한 입력 없이도 내가 만든 장면이 바로 소리가 된다`는 감각적 창작 경험이다. 초기 MVP에서는 완전 자유 스케치 해석보다, 몇 개의 대표 모티프를 미리 제공하고 사용자가 이를 선택하거나 따라 그리게 함으로써 예측 가능하고 안정적인 반응을 우선한다.

즉 MVP의 핵심은 `자유 드로잉 인식 정확도`가 아니라, `쉬운 입력`, `빠른 피드백`, `신뢰 가능한 사운드 반응`이다.

## 2. 문제 정의
사용자들은 그림 그리기 자체는 익숙하지만, 자유롭게 그린 입력이 시스템에 의해 불안정하게 해석되면 결과를 신뢰하기 어렵다. 특히 초심자에게는 `어떻게 그려야 원하는 반응이 나오는지` 모르는 상태가 큰 스트레스가 된다.

따라서 본 제품은 다음 문제를 해결한다.
- 사용자가 어떤 그림을 입력해야 원하는 장면이 되는지 알기 어렵다.
- 자유 스케치 기반 인식은 초기 MVP에서 오인식 위험이 높다.
- 오인식이 반복되면 사용자는 시스템 반응을 신뢰하지 못하고 이탈한다.
- 복잡한 입력 해석보다, 빠르고 예측 가능한 입력 구조가 초기 사용자 경험에 더 중요하다.

## 3. 목표
### 제품 목표
- 사용자가 최소한의 고민으로 장면을 입력하고 즉시 소리로 반응하는 경험을 제공한다.
- 장면 요소가 누적될수록 BGM과 환경음이 자연스럽게 풍성해지도록 한다.
- 최종적으로 사용자가 자신의 입력으로 개인화된 ASMR 또는 사운드스케이프를 만들었다고 느끼게 한다.
- 사용자가 그림 실력과 무관하게 빠르게 원하는 결과를 만들 수 있게 한다.

### MVP 목표
- 사용자가 미리 제공된 장면 모티프를 선택하거나 따라 그려 빠르게 첫 사운드 반응을 경험한다.
- 사용자는 최소 3개 이상의 모티프를 추가하며 사운드가 누적되는 경험을 한다.
- 첫 입력 후 3초 이내에 첫 오디오 반응이 시작된다.
- 한 세션 안에서 사용자가 직접 만든 사운드 결과를 다시 재생해볼 수 있다.
- 사용자는 입력 방식 때문에 스트레스를 받지 않고 높은 확률로 의도한 모티프에 대응하는 사운드를 얻는다.

MVP acceptance:
- 사용자가 제공된 가이드 또는 아이콘 기반 모티프를 3개 순서대로 입력했을 때 active audio layer 또는 scene element가 누적되며, 기존 레이어가 끊기지 않아야 한다.
- 첫 입력 완료 시점부터 오디오 상태가 첫 재생 가능 상태(`playing` 또는 이에 준하는 노출 상태)로 바뀌기까지 3초를 넘지 않아야 한다.
- pause/replay/reset 조작 후 세션 안에서 다시 현재 장면을 재생할 수 있어야 한다.
- 사용자는 무엇을 그리면 어떤 반응이 나오는지 대략 예측할 수 있어야 하며, 입력 방식 때문에 스트레스를 받아서는 안 된다.

## 4. 비목표
- 전문 음악 제작 툴 수준의 정밀 편집 기능 제공
- 악기 작곡, BPM 조정, 믹싱 콘솔 같은 고급 오디오 기능 제공
- 자유 텍스트 프롬프트 기반의 완전 생성형 음악 제작
- 성인 전문가용 ASMR 제작 스튜디오 포지셔닝
- 초기 MVP에서 완전 자유 스케치 인식 품질을 주된 경쟁력으로 삼기

## 5. 핵심 사용자
### 학생 사용자
`초등학생, 중학생, 고등학생`

학생 사용자는 복잡한 오디오 편집이나 시각 도구 선택 없이도 간단한 입력만으로 분위기를 만들고 싶어 한다. 핵심 사용 맥락은 장면 가이드를 따라 쉽게 결과를 만들고, 그 장면이 곧바로 사운드로 확장되며, 공부 전 집중하거나 쉬는 시간에 자신만의 배경음을 만드는 것이다.

### 성인 사용자
`대학생 및 일반 성인`

성인 사용자는 놀이성보다 `집중`, `휴식`, `감정 전환`, `가벼운 창작`에 더 큰 가치를 둔다. 이들은 짧은 시간 안에 자신이 원하는 무드의 사운드 풍경을 빠르게 만들고, 반복 재생하며 개인화된 ASMR처럼 활용하고자 한다. 시각 표현은 자유도보다 빠르고 부담 없는 입력이 중요하다.

## 7. 핵심 유즈 케이스
### 유즈 케이스 1: 사용자가 가이드를 따라 첫 소리를 쉽게 만든다
민서는 빈 캔버스에서 `캠프파이어` 가이드를 선택하거나 제시된 형태를 따라 그린다. 시스템은 이를 안정적으로 캠프파이어 모티프로 해석하고, 즉시 잔잔한 불타는 소리와 어울리는 배경음을 재생한다. 사용자는 `어떻게 입력해야 하는지` 고민하지 않고 첫 성공 경험을 얻어야 한다.

성공 조건:
- 사용자는 별도 학습 없이 어떤 입력이 가능한지 이해한다.
- 입력 후 짧은 시간 안에 소리가 시작된다.
- 시스템 반응이 사용자의 기대와 크게 어긋나지 않는다.
- 테스트 관점에서 첫 입력 완료 이후 오디오 상태 전이가 관찰 가능해야 한다.

### 유즈 케이스 2: 모티프를 추가할수록 사운드가 레이어로 쌓인다
민서는 캠프파이어 뒤에 `별`, `나무`, `비` 같은 가이드를 추가 입력한다. 시스템은 새 입력이 추가될 때마다 기존 사운드를 끊지 않고, 해당 모티프에 맞는 추가 레이어를 얹는다. 사용자는 자신의 선택과 입력이 하나의 풍경과 분위기를 만든다고 느껴야 한다.

성공 조건:
- 새 모티프가 추가되어도 기존 사운드가 갑자기 끊기지 않는다.
- 각 레이어가 과하게 충돌하지 않고 자연스럽게 섞인다.
- 사용자는 입력이 늘어날수록 결과가 더 풍성해졌다고 느낀다.
- 테스트 관점에서 모티프 추가 후 active layer 수 또는 scene element 수가 증가해야 한다.

### 유즈 케이스 3: 사용자가 자신의 ASMR을 재생하며 몰입한다
서윤은 `비`, `창문`, `책상`, `작은 조명` 같은 입력 가이드를 사용해 조용한 작업 분위기를 만든다. 완성 후 한 번 더 들어보면서 자신이 만든 사운드가 집중용 배경음처럼 느껴지는지 확인한다.

성공 조건:
- 사용자는 현재 만들어진 사운드를 끊김 없이 계속 들을 수 있다.
- 사용자는 자신의 결과물을 `내가 만든 분위기`로 인식한다.
- 최소한 세션 내 재생과 초기화는 쉽게 할 수 있어야 한다.
- 테스트 관점에서 pause 후 replay 시 다시 `playing` 상태로 돌아와야 한다.

### 유즈 케이스 4: 초심자도 시행착오 없이 반복해서 시도한다
사용자는 처음 서비스를 접했을 때 자유롭게 낙서해서 인식 결과를 맞추려 애쓸 필요가 없어야 한다. 시스템은 몇 개의 대표 모티프를 가이드 형태로 제공하고, 사용자는 이를 따라 그리거나 선택함으로써 쉽게 장면을 구성할 수 있어야 한다.

성공 조건:
- 사용자는 `어떻게 그려야 하나`를 고민하지 않아도 된다.
- 입력 결과가 예측 가능하고, 실패 경험이 적다.
- 인식 불확실성은 가능한 한 UI와 입력 구조에서 제거된다.
- 테스트 관점에서 지원된 모티프 입력은 높은 재현성으로 같은 scene/audio 결과를 만들어야 한다.

### 유즈 케이스 5: 사용자가 잘못 입력한 요소를 수정하고 사운드를 바로 바로잡는다
민서는 나무 가이드를 선택했지만 입력을 어설프게 끝내 원하는 결과가 나오지 않았음을 알아차린다. 사용자는 해당 입력을 되돌리거나 초기화하고 다시 시도할 수 있어야 하며, 시스템은 수정된 결과에 맞춰 기존 사운드 레이어도 함께 정리해야 한다. 사용자는 실수해도 전체 장면이 망가졌다고 느끼지 않고, 쉽게 다시 시도할 수 있어야 한다.

성공 조건:
- 사용자는 최근 입력을 `되돌리기` 하거나 전체 세션을 `초기화` 할 수 있다.
- 제거된 입력에 연결된 사운드 레이어도 즉시 중지되거나 자연스럽게 빠져야 한다.
- 수정 후 다시 입력한 결과에 따라 새 사운드가 반영되어야 한다.
- 수정 과정이 복잡하지 않아 학생과 성인 모두 바로 이해할 수 있어야 한다.
- 테스트 관점에서 undo 또는 reset 후 active layer 수가 감소하고, 재입력 시 다시 증가해야 한다.

## 8. 사용자 여정
1. 사용자가 웹사이트에 접속한다.
2. 빈 캔버스와 함께 몇 개의 대표 모티프 가이드 또는 예시 아이콘을 본다.
3. 사용자는 원하는 모티프를 선택하거나 안내된 형태를 따라 첫 입력을 한다.
4. 시스템이 해당 입력을 안정적으로 해석하고 첫 사운드/BGM을 재생한다.
5. 사용자가 추가 모티프를 계속 입력한다.
6. 사운드 레이어가 누적되어 더 풍성한 배경음이 된다.
7. 사용자는 필요하면 일부 입력을 되돌리거나 초기화해 장면과 사운드를 수정한다.
8. 사용자는 계속 듣거나, 다시 입력하거나, 초기화해 새 장면을 만든다.

## 9. MVP 기능 요구사항
### 필수 기능
- 사용자는 미리 제공된 대표 모티프 가이드 또는 아이콘을 볼 수 있어야 한다.
- 사용자는 선택한 모티프를 따라 그리거나, 제한된 방식으로 입력할 수 있어야 한다.
- 시스템은 입력 완료 후 해당 모티프 또는 장면 요소를 안정적으로 해석할 수 있어야 한다.
- 시스템은 해석 결과에 맞는 BGM 또는 환경음을 즉시 재생해야 한다.
- 추가 입력이 생기면 기존 사운드 위에 새 사운드를 레이어로 추가해야 한다.
- 사용자는 최근 입력을 되돌리거나 전체 세션을 초기화할 수 있어야 한다.
- 사용자는 현재 사운드 상태를 계속 들을 수 있어야 한다.
- 사용자는 현재 어떤 모티프가 쌓였는지 간단히 확인할 수 있어야 한다.

### 권장 기능
- 따라 그리기 힌트 또는 반투명 guide overlay
- 현재 입력 가능한 대표 모티프 목록 표시
- 재생/일시정지 버튼 제공
- 추후 자유 드로잉 모드로 확장 가능한 입력 구조 유지

## 10. 시스템 동작 원칙
- `즉시성`: 첫 반응이 빨라야 한다. 완벽한 해석보다 빠른 피드백이 우선이다.
- `예측 가능성`: 사용자는 어떤 입력이 어떤 반응으로 이어질지 대략 이해할 수 있어야 한다.
- `누적성`: 새 입력은 기존 결과를 대체하기보다 확장해야 한다.
- `직관성`: 학생과 성인 모두 설명 없이도 대략 사용할 수 있어야 한다.
- `안정성`: 입력을 여러 번 반복해도 오디오가 갑자기 깨지거나 멈추지 않아야 한다.
- `저스트-이너프 제약`: 초기 MVP에서는 표현 자유도보다 쉬운 입력과 높은 성공률을 우선한다.

## 11. MVP 콘텐츠 범위
초기 MVP는 자유로운 모든 그림을 처리하려 하기보다, 아래와 같은 `가이드 제공이 쉬운 대표 모티프`부터 지원한다.

- 자연: 비, 바람, 나무, 바다, 별
- 휴식: 캠프파이어, 창문, 조명
- 작업/집중: 책상, 연필, 종이

초기에는 완전한 자유 스케치 인식보다 `대표 모티프 선택 또는 따라 그리기 + 결정적 장면 매핑`을 우선한다. 시각 입력은 부담 없는 단순 선 입력을 유지하되, 무엇을 어떻게 입력해야 하는지 시스템이 먼저 안내한다.

## 12. 성공 지표
### 정량 지표
- 세션당 평균 입력 요소 수
- 첫 사운드가 재생되기까지 걸리는 시간
- 한 세션 내 재생 지속 시간
- 초기화 후 재시작 비율

### 정성 지표
- 사용자가 `내가 만든 것이 바로 소리가 되었다`고 느끼는지
- 사용자가 `더 추가하고 싶다`는 반응을 보이는지
- 사용자가 결과를 `내가 만든 분위기` 혹은 `내 ASMR`로 표현하는지

## 13. 리스크와 가정
### 가정
- 초기 사용자는 표현 자유도보다 빠른 성공 경험과 예측 가능한 반응을 더 중요하게 여긴다.
- 제한된 모티프 세트만으로도 충분히 재미와 몰입을 줄 수 있다.
- 가이드 기반 입력은 초심자의 진입 장벽을 낮추고 반복 사용을 높인다.

### 리스크
- 입력을 너무 제한하면 사용자가 창의성이 부족하다고 느낄 수 있다.
- prebuilt motif 수가 너무 적으면 금방 반복적으로 느껴질 수 있다.
- guided input이 `그리기`보다 `선택`처럼 느껴지면 제품의 감성적 가치가 약해질 수 있다.
- 자유 드로잉 기대를 가진 사용자가 MVP 입력 구조를 답답하게 느낄 수 있다.

## 14. 향후 확장 아이디어
- 완성한 사운드 풍경 저장
- 친구나 가족과 결과 공유
- 특정 테마 팩 제공: 비 오는 밤, 숲속 캠프, 공부방 등
- 자유 드로잉 모드 또는 hybrid mode 추가

## 15. 오픈 질문
- guided input을 기본값으로 둘지, 자유 드로잉과 병행할지 결정이 필요하다.
- prebuilt motif는 몇 개까지가 MVP 범위로 적절한지 결정이 필요하다.
- 사용자가 `선택`만 하게 할지, `따라 그리기`까지 요구할지 결정이 필요하다.
- guided input에서 입력 성공 판정 기준을 얼마나 엄격하게 둘지 결정이 필요하다.
- 자유 드로잉 기반 인식 확장은 MVP 이후 어느 시점에 다시 검토할지 결정이 필요하다.
