## 1. 제품 개요
BGM Canvas는 사용자가 캔버스 위에 최소한의 입력으로 자유롭게 그림을 그리면, 시스템이 그림의 의미나 분위기를 해석해 어울리는 BGM과 환경음을 추가하는 웹 서비스다. 사용자가 새로운 요소를 계속 그릴수록 사운드는 단일 효과음이 아니라 여러 레이어가 쌓인 풍성한 배경음으로 발전한다.

이 제품의 핵심 가치는 `그림을 통해 나만의 소리 풍경을 만든다`는 감각적 창작 경험이다. 사용자는 음악 이론이나 편집 툴을 몰라도, 검은색 단일 선 드로잉만으로 자신이 원하는 장면과 그에 맞는 ASMR 같은 청각 환경을 만들 수 있어야 한다.

## 2. 문제 정의
사용자들은 그림 그리기 자체는 익숙하지만, 자신이 만든 시각적 결과물이 즉시 청각적 반응으로 확장되는 경험은 드물다. 기존 드로잉 서비스는 주로 시각 결과에만 집중하고, 오디오 서비스는 보통 검색이나 복잡한 조작을 전제로 한다.

따라서 본 제품은 다음 문제를 해결한다.
- 사용자가 그린 결과물이 즉시 살아 움직이는 것처럼 느껴지는 반응이 부족하다.
- 비전문 사용자가 직접 자신의 분위기에 맞는 배경음이나 ASMR을 만들기 어렵다.
- 창작 도구와 휴식 도구가 분리되어 있어, 그림과 소리를 한 번에 경험하기 어렵다.
- 색상, 브러시, 세부 설정이 많아질수록 사용자는 원하는 결과를 만들기 전에 피로를 느낄 수 있다.

## 3. 목표
### 제품 목표
- 사용자가 그림을 그리는 즉시 소리로 반응하는 경험을 제공한다.
- 그림 요소가 누적될수록 BGM과 환경음이 자연스럽게 풍성해지도록 한다.
- 최종적으로 사용자가 자신의 그림으로 개인화된 ASMR 또는 사운드스케이프를 만들었다고 느끼게 한다.
- 사용자가 색상이나 도구 선택 없이도 빠르게 원하는 장면을 만들 수 있게 한다.

### MVP 목표
- 사용자가 최소 3개 이상의 그림 요소를 추가하며 사운드가 누적되는 경험을 한다.
- 첫 드로잉 후 3초 이내에 첫 오디오 반응이 시작된다.
- 한 세션 안에서 사용자가 직접 만든 사운드 결과를 다시 재생해볼 수 있다.
- 사용자가 별도 설정 없이 입장 직후 바로 검은색 단일 선으로 그림을 시작할 수 있다.

MVP acceptance:
- 요소 3개를 순서대로 추가했을 때 active audio layer 또는 scene element가 누적되며, 기존 레이어가 끊기지 않아야 한다.
- 첫 stroke 완료 시점부터 오디오 상태가 첫 재생 가능 상태(`playing` 또는 이에 준하는 노출 상태)로 바뀌기까지 3초를 넘지 않아야 한다.
- pause/replay/reset 조작 후 세션 안에서 다시 현재 장면을 재생할 수 있어야 한다.
- 첫 화면 진입 직후 별도 모드 선택 없이 pointer 입력으로 바로 첫 stroke를 시작할 수 있어야 한다.

## 4. 비목표
- 전문 음악 제작 툴 수준의 정밀 편집 기능 제공
- 악기 작곡, BPM 조정, 믹싱 콘솔 같은 고급 오디오 기능 제공
- 자유 텍스트 프롬프트 기반의 완전 생성형 음악 제작
- 성인 전문가용 ASMR 제작 스튜디오 포지셔닝
- 다중 브러시, 색상 팔레트, 채색 중심의 드로잉 툴 제공

## 5. 핵심 사용자
### 학생 사용자
`초등학생, 중학생, 고등학생`

학생 사용자는 복잡한 오디오 편집이나 시각 도구 선택 없이도 그림만으로 분위기를 만들고 싶어 한다. 핵심 사용 맥락은 낙서하듯 장면을 그리고, 그 장면이 곧바로 사운드로 확장되며, 공부 전 집중하거나 쉬는 시간에 자신만의 배경음을 만드는 것이다.

### 성인 사용자
`대학생 및 일반 성인`

성인 사용자는 놀이성보다 `집중`, `휴식`, `감정 전환`, `가벼운 창작`에 더 큰 가치를 둔다. 이들은 짧은 시간 안에 자신이 원하는 무드의 사운드 풍경을 빠르게 만들고, 반복 재생하며 개인화된 ASMR처럼 활용하고자 한다. 시각 표현은 화려함보다 빠르고 부담 없는 입력이 중요하다.

## 7. 핵심 유즈 케이스
### 유즈 케이스 1: 그림 한 개가 즉시 소리로 반응한다
민서는 빈 캔버스에 `캠프파이어`를 그린다. 시스템은 이를 불 또는 모닥불 장면으로 인식하고, 즉시 잔잔한 불타는 소리와 어울리는 배경음을 재생한다. 사용자는 `내 그림이 바로 소리가 된다`는 첫 인상을 받아야 한다.

성공 조건:
- 그림 입력 후 짧은 시간 안에 소리가 시작된다.
- 소리가 너무 복잡하지 않고, 사용자가 그린 대상과 직관적으로 연결된다.
- 테스트 관점에서 첫 stroke 완료 이후 오디오 상태 전이가 관찰 가능해야 한다.

### 유즈 케이스 2: 그림이 늘어날수록 사운드가 레이어로 쌓인다
민서는 캠프파이어 옆에 `별`, `나무`, `텐트`를 추가로 그린다. 시스템은 새 그림이 추가될 때마다 기존 사운드를 끊지 않고, 장면에 맞는 추가 레이어를 얹는다. 사용자는 자신의 그림이 하나의 풍경과 분위기를 만든다고 느껴야 한다.

성공 조건:
- 새 요소가 추가되어도 기존 사운드가 갑자기 끊기지 않는다.
- 각 레이어가 과하게 충돌하지 않고 자연스럽게 섞인다.
- 사용자는 그림이 많아질수록 결과가 더 풍성해졌다고 느낀다.
- 테스트 관점에서 요소 추가 후 active layer 수 또는 scene element 수가 증가해야 한다.

### 유즈 케이스 3: 사용자가 자신의 ASMR을 재생하며 몰입한다
서윤은 `비`, `창문`, `책상`, `작은 조명` 같은 그림을 그려 조용한 작업 분위기를 만든다. 완성 후 한 번 더 들어보면서 자신이 만든 사운드가 집중용 배경음처럼 느껴지는지 확인한다.

성공 조건:
- 사용자는 현재 만들어진 사운드를 끊김 없이 계속 들을 수 있다.
- 사용자는 자신의 결과물을 `내가 만든 분위기`로 인식한다.
- 최소한 세션 내 재생과 초기화는 쉽게 할 수 있어야 한다.
- 테스트 관점에서 pause 후 replay 시 다시 `playing` 상태로 돌아와야 한다.

### 유즈 케이스 4: 초심자도 시행착오 없이 반복해서 시도한다
사용자는 처음에 정확하지 않은 그림을 그릴 수 있다. 시스템은 완벽한 드로잉 실력보다 대략적인 형태와 맥락을 기준으로 반응해야 하며, 사용자는 실패했다고 느끼지 않아야 한다.

성공 조건:
- 사용자가 단순하거나 서툰 그림을 그려도 어느 정도 의미 있는 반응이 나온다.
- 인식이 애매할 때는 무음보다 일반적인 분위기 사운드라도 제공한다.
- 테스트 관점에서 애매한 입력은 `unknown` 또는 fallback ambience 정책으로 수렴해야 한다.

### 유즈 케이스 5: 사용자가 잘못 그린 요소를 수정하고 사운드를 바로 바로잡는다
민서는 나무를 그리려다가 형태가 어긋나 원하지 않는 사운드가 추가된 것을 알아차린다. 사용자는 해당 요소를 지우거나 되돌리고 다시 그릴 수 있어야 하며, 시스템은 수정된 결과에 맞춰 기존 사운드 레이어도 함께 정리해야 한다. 사용자는 실수해도 전체 장면이 망가졌다고 느끼지 않고, 쉽게 다시 시도할 수 있어야 한다.

성공 조건:
- 사용자는 최근 드로잉을 `되돌리기` 하거나 특정 요소를 `지우기` 할 수 있다.
- 잘못 인식된 요소를 제거하면 연결된 사운드 레이어도 즉시 중지되거나 자연스럽게 빠져야 한다.
- 수정 후 다시 그린 결과에 따라 새 사운드가 반영되어야 한다.
- 수정 과정이 복잡하지 않아 학생과 성인 모두 바로 이해할 수 있어야 한다.
- 테스트 관점에서 undo 또는 delete 후 active layer 수가 감소하고, 재드로잉 시 다시 증가해야 한다.

## 8. 사용자 여정
1. 사용자가 웹사이트에 접속한다.
2. 빈 캔버스와 간단한 안내를 본다.
3. 사용자는 별도 도구 선택 없이 검은색 단일 선으로 첫 그림을 그린다.
4. 시스템이 그림을 해석하고 첫 사운드/BGM을 재생한다.
5. 사용자가 추가 그림을 그린다.
6. 사운드 레이어가 누적되어 더 풍성한 배경음이 된다.
7. 사용자는 필요하면 일부 그림을 지우거나 되돌려 장면과 사운드를 수정한다.
8. 사용자는 계속 듣거나, 다시 그리거나, 초기화해 새 장면을 만든다.

## 9. MVP 기능 요구사항
### 필수 기능
- 사용자는 마우스나 터치로 자유 드로잉을 할 수 있어야 한다.
- 드로잉 입력은 기본적으로 검은색 단일 선으로 고정되어야 한다.
- 사용자는 색상 팔레트나 브러시 종류를 선택하지 않아도 즉시 그림을 시작할 수 있어야 한다.
- 시스템은 드로잉 완료 후 그림의 대표 요소나 장면을 해석할 수 있어야 한다.
- 시스템은 해석 결과에 맞는 BGM 또는 환경음을 즉시 재생해야 한다.
- 추가 드로잉이 생기면 기존 사운드 위에 새 사운드를 레이어로 추가해야 한다.
- 사용자는 최근 드로잉을 되돌리거나 특정 요소를 지울 수 있어야 한다.
- 요소가 삭제되면 연결된 사운드 레이어도 함께 제거되거나 감쇠되어야 한다.
- 사용자는 현재 사운드 상태를 계속 들을 수 있어야 한다.
- 사용자는 캔버스와 사운드를 한 번에 초기화할 수 있어야 한다.

### 권장 기능
- 대표 그림 카테고리 제공: 예) 불, 비, 바람, 숲, 별, 집, 바다
- 현재 장면에 어떤 사운드가 쌓였는지 간단히 표시
- 재생/일시정지 버튼 제공

## 10. 시스템 동작 원칙
- `즉시성`: 첫 반응이 빨라야 한다. 완벽한 분석보다 빠른 피드백이 우선이다.
- `누적성`: 새 그림은 기존 결과를 대체하기보다 확장해야 한다.
- `직관성`: 학생과 성인 모두 설명 없이도 이해할 수 있어야 한다.
- `안정성`: 그림을 여러 번 그려도 오디오가 갑자기 깨지거나 멈추지 않아야 한다.
- `관용성`: 서툰 그림에도 최대한 긍정적으로 반응해야 한다.
- `최소 입력`: 색상과 브러시 선택 같은 부가 조작 없이 바로 결과를 만들 수 있어야 한다.

## 11. MVP 콘텐츠 범위
초기 MVP는 자유로운 모든 그림을 처리하려 하기보다, 아래와 같은 `분위기 생성에 유리한 대표 모티프`부터 지원한다.

- 자연: 비, 구름, 바람, 나무, 숲, 바다, 별
- 휴식: 캠프파이어, 텐트, 침대, 창문, 조명
- 활동: 빗자루, 발걸음, 종이, 연필

초기에는 사물 단위 완전 인식보다 `대표 모티프 매칭 + 장면 분위기 매핑`을 우선한다. 시각 입력은 채색보다 검은색 단일 선 스케치 해석에 최적화한다.

## 12. 성공 지표
### 정량 지표
- 세션당 평균 드로잉 요소 수
- 첫 사운드가 재생되기까지 걸리는 시간
- 한 세션 내 재생 지속 시간
- 초기화 후 재시작 비율

### 정성 지표
- 사용자가 `내가 그린 것이 소리가 되었다`고 느끼는지
- 사용자가 `더 그리고 싶다`는 반응을 보이는지
- 사용자가 결과를 `내가 만든 분위기` 혹은 `내 ASMR`로 표현하는지

### 가정
- 핵심 사용자는 정교한 인식 정확도보다 즉각적인 반응과 재미를 더 중요하게 여긴다.
- 초기 카테고리 수가 제한적이어도, 반응 품질이 좋으면 만족도가 높다.
- 검은색 단일 선만으로도 사용자는 원하는 장면을 표현하는 데 큰 불편을 느끼지 않는다.

### 리스크
- 그림 인식이 불안정하면 사용자가 왜 이런 소리가 나오는지 이해하지 못할 수 있다.
- 사운드 레이어가 많아질수록 소리가 지저분해질 수 있다.
- 자동 재생 정책 등 브라우저 오디오 제약이 초기 경험을 해칠 수 있다.
- 색상 정보가 없기 때문에 일부 사용자는 표현 자유도가 제한된다고 느낄 수 있다.

## 14. 향후 확장 아이디어
- 완성한 사운드 풍경 저장
- 친구나 가족과 결과 공유
- 특정 테마 팩 제공: 비 오는 밤, 숲속 캠프, 공부방 등
- 감정 기반 모드: 차분함, 집중, 신남, 잠들기 전

## 15. 오픈 질문
- 드로잉 인식은 검은색 자유 스케치 기반으로 갈지, 간단한 도형 가이드와 함께 갈지 결정이 필요하다.
- 사운드 결과를 저장 가능한 결과물로 제공할지, 세션 경험 중심으로 제한할지 결정이 필요하다.
- 학생과 성인 모두 빠르게 진입할 수 있는 최소 텍스트 온보딩 방식이 필요하다.
